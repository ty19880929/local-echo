00 变更说明

1 文件卡片操作行

「打开」「打开文件夹」各占卡片一半，文字居中，悬停时整半块变色，点击区比原来按文字宽度排列大得多。「打开所在文件夹」改为「打开文件夹」。本地文件被移动、改名或删除后，原来直接隐藏操作行，用户不知道原因；现在在同一位置显示「文件已被移动或删除」，行高和上边框不变，卡片高度不跳。

2 本机 IP 移到设置页

侧边栏删除本机 IP 区，直接从「联系人」开始，联系人列表多出约 44 px。顶部内边距保持 8，与条目左右内缩一致，不另加留白。设置页新增第一组「本机 IP」，用表格列出网卡、IP 和复制按钮；整行标题可收起，收起后仍显示第一个 IP 和总数。

3 底栏对齐

新增底栏高度 token = 60（不含上边框）。侧边栏「设置」区 52 → 60；服务器底栏 64 → 60，拖拽区和「上传文件」40 → 36；联系人输入区单行时原本就是 60。三处上边框落在同一像素行，见 3-A 3-B。

4 在远程桌面打开

服务器头部新增第三个次要按钮，图标用 monitor。会话区小于 720 时，「在终端中打开」「在远程桌面打开」收成 32 × 32 图标按钮加 Tooltip，「下载文件」保留文字。新增检测中状态、两条错误 Toast、Linux 专用的「未找到远程桌面客户端」对话框，以及编辑服务器里的「远程桌面端口」。

颜色 token：不新增

需求里卡片操作行的悬停写的是 muted 背景，但深色主题的 muted.background 与卡片的 popover.background 同为 #262424，悬停不可见。因此悬停改用已有的 secondary.background（浅 #E6E4E4 / 深 #2E2B2B），IP 标题行和复制按钮的悬停也用它；按钮悬停沿用 secondary.hover（浅 #DCD9D9 / 深 #383535）。稿中的蓝色 #0A84FF 只是标注，不进入主题。

文案建议（稿中仍按原文案绘制）

端口不通的 Toast 在 400 宽下仍要 3 行，可拆为标题「无法连接 {host}:{port}」+ 正文，或在 Toast 内加「编辑服务器」链接，省去用户自己找入口。「远程桌面端口」标签后加了 muted 的「选填」。未找到客户端对话框里，发行版名称单独放在命令上方，复制时只复制命令本身。
