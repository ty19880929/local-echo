Local Echo 规范

高保真界面品牌与 Logo

设计说明

Logo 寓意

两个点代表局域网里的两台机器，各自发出的一道弧在中间相遇，是一次没有中间人的往返。图形只有点和等粗弧线，16 px 下仍可辨认，单色与反白都成立；刻意避开云、地球和单向发射的波纹。

色彩

整套界面只有一个强调色：红。品牌红 #EC3013 用于 Logo；界面里的 primary 取深一级的 #DD2B0F，让白字在我方气泡和主按钮上达到 AA（4.8 : 1）。其余全部是带一点暖调的中性灰。错误状态同属红色系，因此失败一律配图标和文字（「发送失败 · 重试」），不只靠颜色区分。

形态

零圆角、1 px 边框、只在浮层上用阴影。气泡、卡片、按钮全部是直角矩形，靠色块与左右位置区分双方，和「工程感、安静」的品牌词一致。这一点与需求中的「小圆角」不同：圆角在主题中集中为 radius / radius.lg 两个值，改为 4 px 只需改这两处，设计稿其余部分不受影响。

设置放在哪

建议在右侧会话区内显示，侧边栏底部「设置」保持选中态。设置项只有两组，用对话框会显得空；放在会话区里，迁移确认和进度再用对话框叠加，层级清楚。

关键交互取舍

服务器会话没有输入框，底部只留拖拽区和「上传文件」，避免用户以为能执行命令。设备不匹配的失败提示直接给出「编辑」，一步打开编辑联系人；同名文件确认只列出有同名记录的文件，超过 4 行在列表内滚动。远程目录浏览器在「选择目录」模式下文件置灰不可选；「选择文件」模式靠行选中态多选，不额外加复选框列。传输中的卡片右上角给出取消（x），失败卡片把「重试」放在卡片底部操作行。

文案建议

多 IP 时，标题写「本机 IP（点击复制）」，每行附网卡名（以太网 / WLAN）。「下载文件」打开的浏览器标题用「下载文件」，「更改」打开的用「选择远程目录」。迁移确认补一句「切换后应用会自动重启」，让用户在点击前就知道。端口占用错误加标题「无法启动 Local Echo」。「退出 Local Echo」旁补一句「关闭窗口时 Local Echo 会继续在托盘中运行」，解释它和关闭窗口的区别。
